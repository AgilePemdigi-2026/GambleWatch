# Scripts

Jalankan semua skrip dari root repo.

| File | Fungsi |
|---|---|
| `install_deps.py` | Instal dependensi Python inti |
| `install_ocr.py` | Instal dependensi OCR (DET-03) |
| `install_and_test_ocr.bat` | Instal dan uji OCR di Windows |
| `check_imports.py` | Cek dependensi terpasang |
| `check_ocr_deps.py` | Cek dependensi OCR (Tesseract, Pillow, dll.) |
| `build_reference_index.py` | Bangun reference index untuk DET-02 |
| `evaluate.py` | Evaluasi detektor (butuh `pandas`) |
| `demos/` | Skrip demo yang hanya mencetak hasil |

Petunjuk instal Tesseract: [`docs/INSTALL_TESSERACT.md`](../docs/INSTALL_TESSERACT.md).
